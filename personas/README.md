# Personas do Escritório

Três modos de trabalho com Claude. Escolha um conforme o que precisa fazer.

| Persona | Quando usar | Arquivo |
|---|---|---|
| **Advogado-Desenvolvedor** | Pesquisa jurídica + automação de processos legais | `advogado-desenvolvedor.md` |
| **Desenvolvedor** | Implementar, corrigir, subir código | `desenvolvedor.md` |
| **Parceiro de Trabalho** | Pensar junto, explorar ideias, desbloquear problemas | `parceiro-de-trabalho.md` |

## Como usar

**Opção 1 — Copiar e colar:**
Abra o arquivo da persona, copie o "Prompt de Ativação" e cole no início da conversa.

**Opção 2 — Projeto do Claude (recomendado):**
1. Acesse claude.ai → Projects → Novo Projeto
2. Crie um projeto por persona (ex: "Escritório — Dev", "Escritório — Jurídico")
3. Em "Custom Instructions", cole o Prompt de Ativação correspondente
4. Todas as conversas naquele projeto já usam a persona automaticamente

**Opção 3 — Claude Code (terminal):**
Copie o conteúdo do arquivo para o `CLAUDE.md` na raiz do projeto antes de iniciar uma sessão.
